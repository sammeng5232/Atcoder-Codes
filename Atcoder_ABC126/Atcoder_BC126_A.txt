# [ABC126A] Changing a Character

## 题面翻译

## 输入格式
输入共两行。第一行两个整数 $n,k$ 。

第二行一个由 `A`,`B`,`C` 组成字符串  $s$ 。

$n$ 表示字符串的长度。

把字符串 $s$ 的第 $k-1$ 个字符变成小写。（字符串 $s$ 的第一个字符的下标为 $0$ ）

## 输出格式
一行一个字符串 $s$ ，为转换后的字符串。

## 题目描述

[problemUrl]: https://atcoder.jp/contests/abc126/tasks/abc126_a

`A`, `B`, `C` からなる長さ $ N $ の文字列 $ S $ と、$ 1 $ 以上 $ N $ 以下の整数 $ K $ が与えられます。 文字列 $ S $ の $ K $ 文字目を小文字に書き換え、新しくできた $ S $ を出力してください。

## 输入格式

入力は以下の形式で標準入力から与えられる。

> $ N $ $ K $ $ S $

## 输出格式

文字列 $ S $ の $ K $ 文字目を小文字に書き換え、新しくできた $ S $ を出力せよ。

## 样例 #1

### 样例输入 #1

```
3 1
ABC
```

### 样例输出 #1

```
aBC
```

## 样例 #2

### 样例输入 #2

```
4 3
CABA
```

### 样例输出 #2

```
CAbA
```

## 提示

### 制約

- $ 1\ <\ =\ N\ <\ =\ 50 $
- $ 1\ <\ =\ K\ <\ =\ N $
- $ S $ は `A`, `B`, `C` からなる長さ $ N $ の文字列

#include<bits/stdc++.h>
using namespace std;

int main (){
	int n,k;cin>>n>>k;
	string a;cin>>a;
	for (int i=0;i<k-1;i++)cout<<a[i];
	if (a[k-1]=='A') cout<<'a';
	if (a[k-1]=='B') cout<<'b';
	if (a[k-1]=='C') cout<<'c';
	if (a[k-1]=='D') cout<<'d';
	if (a[k-1]=='E') cout<<'e';
	if (a[k-1]=='F') cout<<'f';
	if (a[k-1]=='G') cout<<'g';
	if (a[k-1]=='H') cout<<'h';
	if (a[k-1]=='I') cout<<'i';
	if (a[k-1]=='J') cout<<'j';
	if (a[k-1]=='K') cout<<'k';
	if (a[k-1]=='L') cout<<'l';
	if (a[k-1]=='M') cout<<'m';
	if (a[k-1]=='N') cout<<'n';
	if (a[k-1]=='O') cout<<'o';
	if (a[k-1]=='P') cout<<'p';
	if (a[k-1]=='Q') cout<<'q';
	if (a[k-1]=='R') cout<<'r';
	if (a[k-1]=='S') cout<<'s';
	if (a[k-1]=='T') cout<<'t';
	if (a[k-1]=='U') cout<<'u';
	if (a[k-1]=='V') cout<<'v';
	if (a[k-1]=='W') cout<<'w';
	if (a[k-1]=='X') cout<<'x';
	if (a[k-1]=='Y') cout<<'y';
	if (a[k-1]=='Z') cout<<'z';
	for (int i=k;i<n;i++)cout<<a[i];
	cout<<endl;
	return 0;
}
