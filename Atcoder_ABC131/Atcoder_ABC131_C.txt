# [ABC131C] Anti-Division

## 题面翻译

给出四个整数 $A,B,C$ 和 $D$。 查找 $A$ 和 $B$之间（包含 $A,B$）不能被 $C$ 或 $D$ 整除的整数个数。

## 题目描述

[problemUrl]: https://atcoder.jp/contests/abc131/tasks/abc131_c

整数 $ A,B,C,D $ が与えられます。$ A $ 以上 $ B $ 以下の整数のうち、$ C $ でも $ D $ でも割り切れないものの個数を求めてください。

## 输入格式

入力は以下の形式で標準入力から与えられる。

> $ A $ $ B $ $ C $ $ D $

## 输出格式

$ A $ 以上 $ B $ 以下の整数のうち、$ C $ でも $ D $ でも割り切れないものの個数を出力せよ。

## 样例 #1

### 样例输入 #1

```
4 9 2 3
```

### 样例输出 #1

```
2
```

## 样例 #2

### 样例输入 #2

```
10 40 6 8
```

### 样例输出 #2

```
23
```

## 样例 #3

### 样例输入 #3

```
314159265358979323 846264338327950288 419716939 937510582
```

### 样例输出 #3

```
532105071133627368
```

## 提示

### 制約

- $ 1\leq\ A\leq\ B\leq\ 10^{18} $
- $ 1\leq\ C,D\leq\ 10^9 $
- 入力はすべて整数である

### Sample Explanation 1

$ 5,7 $ が条件を満たします。

#include<bits/stdc++.h>
using namespace std;

long long gcd(long long a,long long b){
    if(b==0) return a;
    a%=b;
    return gcd(b,a);
}

long long lcm(long long a,long long b){
	return a*b/gcd(a,b); 
}

int main (){
	long long a,b,c,d;cin>>a>>b>>c>>d;
	cout<<(b-a+1-(((b-b%c)-(a+(c-a%c)%c))/c+1))+(b-a+1-(((b-b%d)-(a+(d-a%d)%d))/d+1))-(b-a+1-(((b-(b%(lcm(c,d))))-(a+((lcm(c,d))-a%(lcm(c,d)))%(lcm(c,d))))/(lcm(c,d))+1))<<endl;
	return 0;
}
