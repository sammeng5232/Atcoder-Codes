# AtCoder Solutions

Solutions to [AtCoder](https://atcoder.jp/) contests. Handle: [telamath](https://atcoder.jp/users/telamath).

## Contents

- 42 contests: Beginner Contests 126–157, 260, 366–379; Regular Contests 144, 183; and one-off contests (Diverta 2019, JSC2019 Qual, M-Solutions 2019, Tenka1 2019)
- 161 problem write-ups + 22 editorial / problem PDFs

## Format

Each write-up (`Atcoder_BC<contest>_<problem>.txt`) contains the problem statement (Chinese translation), the analysis, and C++ code. Folders and files use `BC` (Beginner Contest) / `RC` (Regular Contest) prefixes.

    Atcoder_BC126/                Beginner Contest 126
      Atcoder_BC126_A.txt         problem A write-up
      Atcoder_BC126_Editorial.pdf
    Atcoder_RC144/                Regular Contest 144
    Atcoder_Tenka1_BC2019/        Tenka1 2019 (Beginner)
