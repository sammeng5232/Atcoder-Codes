# [ABC367D] Pedometer

## 题面翻译

### 题目描述

一个湖泊周围有 $N$ 个休憩所。这些休憩所按顺时针方向被标记为 $1, 2, \ldots, N$。从休憩所 $i$ 到休憩所 $i+1$（其中休憩所 $N+1$ 指的是休憩所 $1$）顺时针行走需要 $A_i$ 步。已知从某个休憩所 $s$ 到另一个不同的休憩所 $t$ 顺时针行走的最短步数是 $M$ 的倍数。我们需要计算所有可能的 $(s,t)$ 组合的数量。

### 输入格式

输入数据以以下格式从标准输入给出：

> $N$ $M$ $A_1$ $A_2$ $\ldots$ $A_N$

### 输出格式

输出答案作为一个整数。

### 提示

#### 制约条件

- 所有输入数据都是整数。
- $2 \le N \le 2 \times 10^5$
- $1 \le A_i \le 10^9$
- $1 \le M \le 10^6$

#### 示例解释 1

- 从休憩所 $1$ 到休憩所 $2$ 顺时针行走的最短步数是 $2$ 步，这不是 $3$ 的倍数。
- 从休憩所 $1$ 到休憩所 $3$ 顺时针行走的最短步数是 $3$ 步，这是 $3$ 的倍数。
- 从休憩所 $1$ 到休憩所 $4$ 顺时针行走的最短步数是 $7$ 步，这不是 $3$ 的倍数。
- 从休憩所 $2$ 到休憩所 $3$ 顺时针行走的最短步数是 $1$ 歩，这不是 $3$ 的倍数。
- 从休憩所 $2$ 到休憩所 $4$ 顺时针行走的最短步数是 $5$ 步，这不是 $3$ 的倍数。
- 从休憩所 $2$ 回到休憩所 $1$ 顺时针行走的最短步数是 $8$ 步，这不是 $3$ 的倍数。
- 从休憩所 $3$ 到休憩所 $4$ 顺时针行走的最短步数是 $4$ 步，这不是 $3$ 的倍数。
- 从休憩所 $3$ 回到休憩所 $1$ 顺时针行走的最短步数是 $7$ 步，这不是 $3$ 的倍数。
- 从休憩所 $3$ 回到休憩所 $2$ 顺时针行走的最短步数是 $9$ 步，这是 $3$ 的倍数。
- 从休憩所 $4$ 回到休憩所 $1$ 顺时针行走的最短步数是 $3$ 步，这是 $3$ 的倍数。
- 从休憩所 $4$ 回到休憩所 $2$ 顺时针行走的最短步数是 $5$ 步，这不是 $3$ 的倍数。
- 从休憩所 $4$ 回到休憩所 $3$ 顺时针行走的最短步数是 $6$ 步，这是 $3$ 的倍数。

因此，符合条件的 $(s,t)$ 组合数量为 $4$。

## 题目描述

[problemUrl]: https://atcoder.jp/contests/abc367/tasks/abc367_d

湖の周りに $ N $ 個の休憩所があります。  
 休憩所には時計回りに $ 1,2,\dots,N $ の番号が付いています。  
 休憩所 $ i $ から休憩所 $ i+1 $ まで時計回りに歩くには $ A_i $ 歩かかります ( 但し、休憩所 $ N+1 $ は休憩所 $ 1 $ を指します ) 。

 $ (s,t) $ の組として考えられるものの数を求めてください。

Solution: The problem is equivalent to finding the number ans1 of subarrays, in the
array made of concatenating two copies of a, of length less than n, with sum
being a multiple of m; and the number ans2 of subarrays, in the original array
a, of length less than n, with sum being a multiple of m. The result is
ans1-ans2, since those subarrays that ans2 counts is double counted in ans1.

A brute-force approach is to compare every starting point and ending point of a subarray.

Pseudocode 0:
for each starting point i:
  for each ending point j:
    sum=0
    for each i<=k<=j:
      sum+=a[k]
    if (!(sum%m))
      ans++

This has a time complexity of (O(n^3)), which will surely result in TLE.

Next, we use the idea of prefix sum, it stores ps[i]=sum_{1<=j<=i}a[j], so to compute the sum
of each subarray we only need to take a difference of two values in the prefix sum.

Code 1 :
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef unsigned long long ull;
typedef vector<double> vd;
typedef vector<int> vi;
typedef stack<double> sd;
typedef stack<int> si;
typedef queue<double> qd;
typedef queue<int> qi;

int n, m, a[200010];
ll ans, ps[400010];

int main() {
  ios::sync_with_stdio(false);
  cin.tie(0);
  cin >> n >> m;
  for (int i = 1; i <= n; i++) {
    cin >> a[i];
    ps[i] = ps[i - 1] + a[i];
  }
  for (int i = n + 1; i <= 2 * n; i++)
    ps[i] = ps[i - 1] + a[i - n];
  for (int i = 1; i <= n; i++)
    for (int j = i + 1; j <= i + n - 1; j++)
      if (!((ps[j - 1] - ps[i - 1]) % m))
        ans++;
  cout << ans << "\n";
  return 0;
}

This reduces the overall time complexity to O(n^2), but since n can be up to 2*10^5, this
still yields TLE in most of the test cases.

To improve, for each ending point j, instead of iterating the starting point i,
we can store the prefix sum in a frequency array as we compute (and since the range is huge, we
actually do it with a map). Then, to find the number of starting point i that fit with
the ending point j, we just have to look at the frequency array (the map), rather than
searching them all again.

Code 2 :
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef unsigned long long ull;
typedef vector<double> vd;
typedef vector<int> vi;
typedef stack<double> sd;
typedef stack<int> si;
typedef queue<double> qd;
typedef queue<int> qi;

int n, m, a[400010], ps[400010];
ll ans1, ans2;

int main() {
  ios::sync_with_stdio(false);
  cin.tie(0);
  cin >> n >> m;
  for (int i = 1; i <= n; i++) {
    cin >> a[i];
    a[i] %= m;
  }
  for (int i = n + 1; i <= 2 * n; i++)
    a[i] = a[i - n];
  map<int, int> mp1;
  mp1[0] = 1;
  for (int i = 1; i <= 2 * n; i++) {
    ps[i] = (ps[i - 1] + a[i]) % m;
    ans1 += mp1[ps[i]];
    mp1[ps[i]]++;
    if (i >= n - 1)
      mp1[ps[i - (n - 1)]]--;
  }
  map<int, int> mp2;
  mp2[0] = 1;
  for (int i = 1; i <= n; i++) {
    ps[i] = (ps[i - 1] + a[i]) % m;
    ans2 += mp2[ps[i]];
    mp2[ps[i]]++;
    if (i >= n - 1)
      mp2[ps[i - (n - 1)]]--;
  }
  cout << ans1 - ans2 << "\n";
  return 0;
}

This further reduces the time complexity to O(n), and finally yields an AC.
