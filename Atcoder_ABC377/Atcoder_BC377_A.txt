# [ABC377A] Rearranging ABC

## 题面翻译

### 题目描述
给出长度为 $3$ 的由大写字母构成的字符串 $S$。

请判定时候能通过通过重新排列 $S$ 中的各个字符，使得 $S$ 与字符串 `ABC` 一致。
### 输入格式
输入按照如下标准给出：
> $S$
### 输出格式
如果能通过重新排列 $S$ 的各个字符，使其与字符串 `ABC` 一致，则输出 `Yes`，否则输出 `No`。
### 说明/提示
#### 约定 
-   $S$ 是由大写字母组成的长度为 $3$ 的字符串
#### 样例说明 1
可以交换 $S$ 的第 $1$ 个字符和 $S$ 的第 $2$ 个字符，使其与 `ABC` 一致。
#### 样例说明 2

无论如何重新排列都不能使 $S$ 与 `ABC` 一致。

## 题目描述

[problemUrl]: https://atcoder.jp/contests/abc377/tasks/abc377_a

長さ $ 3 $ の英大文字からなる文字列 $ S $ が与えられます。

$ S $ の各文字を並び替えることで $ S $ を文字列 `ABC` と一致させることができるか判定してください。

## 输入格式

入力は以下の形式で標準入力から与えられる。

> $ S $

## 输出格式

$ S $ の各文字を並び替えることで文字列 `ABC` と一致させることができるなら `Yes` を、そうでないなら `No` を出力せよ。

## 提示

### 制約

- $ S $ は英大文字からなる長さ $ 3 $ の文字列

### Sample Explanation 1

$ S $ の $ 1 $ 文字目と $ S $ の $ 2 $ 文字目を入れ替えることで `ABC` と一致させることができます。

### Sample Explanation 2

どのように並び替えても $ S $ を `ABC` と一致させることはできません。

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef unsigned long long ull;
typedef vector<ll> vd;

typedef stack<ll> sd;

int main() {
  ios::sync_with_stdio(false);
  cin.tie(0);
  string s;
  cin >> s;
  int c1 = 0, c2 = 0, c3 = 0;
  for (int i = 0; i < 3; i++) {
    if (s[i] == 'A')
      c1++;
    else if (s[i] == 'B')
      c2++;
    else if (s[i] == 'C')
      c3++;
  }
  cout << ((c1 == c2 && c2 == c3 && c3 == 1) ? "Yes\n" : "No\n");
  return 0;
}
