# [ABC143D] Triangles

## 题面翻译

【问题描述】

小$Z$有$N$条木棍，每条木棍的长度为$D_i$。他想在这$N$条木棍中选择三条，让这三条木棍能构成一个三角形。小$Z$想知道有多少种方案能构成三角形（不同的方案定义为一条木棍在其中一个三角形中出现不在另一个中出现）。

【输入格式】

输入第一行一个整数$N$，表示木棍的个数。

第二行$N$个整数$D_i$，表示木棍的长度。

【输出格式】

输出一个整数，表示构成三角形的方案数。

【样例说明】

样例$1$：只能形成一个三角形：由第一，第二和第三根木棍形成的三角形。

样例$2$：无法形成三角形。

【数据规模与约定】

对于$100\%$的数据，$3 \leq N \le 2×10^3$，$1\le D_i 
\le10^3$。

## 题目描述

[problemUrl]: https://atcoder.jp/contests/abc143/tasks/abc143_d

高橋君は、互いに区別出来る $ N $ 本の棒を持っています。$ i $ 本目の棒の長さは $ L_i $ です。

高橋君は、これらのうち $ 3 $ 本の棒を使って三角形を作ろうとしています。このとき、棒の長さを $ a,\ b,\ c $ として、以下の条件がすべて成り立たなければなりません。

- $ a\ <\ b\ +\ c $
- $ b\ <\ c\ +\ a $
- $ c\ <\ a\ +\ b $

作れる三角形は何種類あるでしょうか。ただし、$ 2 $ つの三角形は、そのうち一方にのみ使われている棒が存在するときに異なるとします。

## 输入格式

入力は以下の形式で標準入力から与えられる。

> $ N $ $ L_1 $ $ L_2 $ $ ... $ $ L_N $

## 输出格式

作れる三角形が何種類あるかを出力せよ。

## 提示

### 制約

- 入力は全て整数
- $ 3\ <\ =\ N\ <\ =\ 2\ \times\ 10^3 $
- $ 1\ \leq\ L_i\ \leq\ 10^3 $

### Sample Explanation 1

作れる三角形は、$ 1 $、$ 2 $、$ 3 $ 番目の棒から成る三角形のみです。

### Sample Explanation 2

作れる三角形はありません。

#include<bits/stdc++.h>
using namespace std;

int main (){
	int n,cnt=0;
    int a[2000];
	scanf("%d",&n);
    for(int i=0;i<n;i++)scanf("%d",&a[i]);
    sort(a,a+n);
    for(int i1=0;i1<n;i1++){
        for(int i2=i1+1;i2<n;i2++){
            for(int i3=i2+1;i3<n;i3++){
                if(a[i1]+a[i2]>a[i3]&&a[i1]+a[i3]>a[i2])cnt++;
                else if(a[i1]+a[i2]<=a[i3])break;
            }
        }
    }
    printf("%d\n",cnt);
	return 0;
}
